Geometry Rules & Formulas

1. Rectangle

Area = base × height

Perimeter = 2 × (length + width)

2. Triangle

Area = ½ × base × perpendicular height

Perimeter = side a + side b + side c

3. Parallelogram

Area = base × perpendicular height

Perimeter = 2 × (base + slant side)

4. Composite Shapes (Last 8 Questions)

Break down the figure into simpler shapes (rectangles, triangles, parallelograms), calculate each sub-area, and add (or subtract cutouts) to find the total!
